# Working agreements

## Tests

Never add tests to the repo unless I explicitly ask for them — no unit, integration,
end-to-end, or benchmark files, and no test scaffolding "while I'm here". If a change
would normally warrant tests, say so in one line and move on.

Verifying your own work is still expected: build it, lint it, run it. Just don't leave
test files behind unless I asked for them.

## Git

Never commit, push, create branches or tags, or open PRs unless I explicitly ask.

Do not ask whether to commit and do not offer it as a next step. Leave the changes in
the working tree and stop — I will say so when I want them committed.

When I do ask for a commit, write a subject line and nothing else — no body. Keep the
reasoning in the conversation, not in the commit message.
